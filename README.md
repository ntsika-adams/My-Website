# TrendWear Clothing Store — Website Project

## Project Overview

TrendWear is a proposed South African clothing e-commerce website for an affordable family-focused fashion retailer. The website is designed to allow customers to browse products, search and filter the catalogue, add products to a shopping cart, complete checkout, choose delivery or click-and-collect, and manage customer accounts.

The project proposal identifies the target users as budget-conscious families, men and women looking for affordable everyday and school clothing, teenagers and young adults using mobile devices, existing TrendWear customers, and customers in areas without convenient access to a physical store.

## Project Goals

The website aims to:

Generate additional online revenue.

Allow customers to browse and purchase products 24/7.

Provide a secure, POPIA-compliant shopping experience.

Reduce queues during busy periods.

Increase TrendWear's online brand awareness.

Reach customers outside existing physical-store areas.

Support registered customer accounts and targeted promotions.

Provide click-and-collect as an alternative to delivery.
